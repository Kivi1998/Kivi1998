# 你好，我是贾昊 👋

也可以叫我 Kivi。目前主要做 AI Agent、RAG 和后端开发，喜欢把新想法做成能用的东西，也会给自己写一些解决日常问题的小工具。

### 平时在做什么

- 折腾 Agent 的任务执行、工具调用和记忆，让它能把事情做完。
- 做 RAG 知识库，关注文档怎么处理、资料怎么找准、回答有没有依据。
- 写后端、接系统、部署服务，也做一些 macOS 应用。

### 常用的家伙

后端主要用 **Python / Java**，常搭配 FastAPI、Spring Boot；Agent 和知识库会用到 LangChain、LangGraph、Elasticsearch。日常也会写点 Swift 和 TypeScript，用 Docker 部署服务。工具按问题选，边做边学。
